# 스마트에디터 ONE 작업 절차

실계정 동작 검증 전인 절차 초안이다. 버튼 이름·위치·저장 표시는 현재 화면으로 확인한다. 공식 도움말은 기능의 근거이며, 아래 자동화가 검증됐다는 뜻은 아니다.

## 작성과 첨부

1. 사용 가능한 도구의 지침에 따라 브라우저·탭을 선택하고 네이버 로그인 여부 및 대상 블로그를 확인한다. 사용자가 브라우저를 지정했다면 그 선택을 따른다.
2. 글쓰기 화면에 기존 작성 내용이 있으면 덮어쓰지 않는다. 현재 글이 이번 작업인지 확인하고, 불명확하면 사용자의 작업을 보존한 채 대상을 확인한다.
3. 제목과 본문을 입력하고 사진·영상을 계획 순서에 넣는다. 에디터는 블록 기반이므로 전체 원고를 붙여넣었다는 이유만으로 사진 위치·줄바꿈이 맞는다고 가정하지 않는다. 일반 텍스트 입력을 기본으로 하고 HTML 삽입 지원을 추정하지 않는다.
4. 실제 파일 선택 기능으로 미디어를 첨부한다. 원본 대신 변환본을 쓸 필요가 있으면 별도 파일로 만들고 변경점을 알린다. 업로드 진행 중인 미디어가 있으면 완료 상태를 확인한다. 영상은 첨부 완료와 재생·처리 완료를 구분한다.
5. 제목, 첫·중간·마지막 문단, 미디어 개수·순서, 캡션과 줄바꿈을 화면에서 점검한다. 사용자 요청에 없는 지도·장소 인증·광고 표기·카테고리를 임의로 추가하지 않는다.

## 임시저장과 확인

- 화면에서 임시저장/저장 기능을 식별한다. 발행·예약 발행은 실행하지 않는다.
- 저장 상태·시각·목록 등 화면에서 제공하는 증거를 작업 기록에 남긴다. 증거에 민감한 계정 정보가 있으면 로컬에만 보관한다.
- 가능하면 저장 후 임시저장 목록에서 해당 제목을 확인하고 다시 열어 본문·첨부 유지 여부를 확인한다. 목록에 접근하려면 미저장 내용 폐기가 필요한 경우 먼저 현재 저장 성공을 확인한다. 저장 확인을 위해 미저장 작업을 버리지 않는다.
- 목록 또는 재열람 확인이 불가능하면 관찰한 범위만 보고한다. `버튼 클릭`, `저장 표시 확인`, `목록 확인`, `재열람 확인`을 구분한다.

## 중단과 재개

- 로그인·추가 인증·캡차가 나오면 사용자에게 해당 단계만 인계한다. 우회하거나 반복 로그인하지 않는다.
- 업로드·저장 결과가 불명확하면 현재 편집 화면과 임시저장 목록부터 확인한다. 같은 글을 새로 만들거나 같은 파일을 다시 첨부하기 전에 중복 여부를 확인한다.
- 한 번의 복구 후에도 같은 오류가 반복되면 로컬 원고·미디어 순서·마지막 확인 상태를 보존하고 인계한다. 화면이 진행 상태라면 추가 클릭 대신 상태를 관찰한다.
- 저장 후 재개 시 로컬 원고와 서버 초안 중 어느 것이 최신인지 확인한다. 사용자가 직접 바꾼 내용을 조용히 덮어쓰지 않는다.
