# naver-blog-draft

사진·영상과 대화로 네이버 블로그 글을 만들고, 컴퓨터 유즈로 스마트에디터 ONE에 옮겨 **임시저장까지** 진행하는 Codex 스킬 초안입니다.

**상태: v0.1.3 초안. 실제 네이버 계정에서의 업로드·임시저장·재열람은 아직 검증하지 않았습니다.** 자동 발행·예약 발행·반복 게시 기능은 포함하지 않습니다. `daily-vlog`와 독립적으로 사용할 수 있으며, 완성된 브이로그를 첨부 자료로 받을 수 있습니다.

## 설치

파일과 명령 실행을 지원하는 Codex에서 작업할 프로젝트를 열고, 아래 내용을 그대로 보내세요. 운영체제 선택이나 Python·Git 사전 설치는 필요 없습니다.

> https://github.com/macro-ai-lab/naver-blog-draft
>
> README를 읽고 이 기능을 설치해줘. 내 실행 환경과 폴더 권한을 확인해서 맞는 방법으로 진행하고, 기존 파일과 개인 지침은 보존해줘. 설치 후 실제 사용 가능한 도구까지 점검해줘. 네이버 글 작성이나 업로드는 아직 하지 마.

Codex가 [설치 절차](INSTALLATION.md)에 따라 환경·허용 경로·기존 설치를 확인합니다. 설치 범위와 실제 점검 결과를 알려주며, 프로젝트에 설치했다면 이후에도 그 프로젝트에서 사용합니다. 설치 과정에 필요한 접근 승인은 앱 안내에 따라 확인합니다.

ZIP을 사용하는 경우에도 **[설치 ZIP](https://github.com/macro-ai-lab/naver-blog-draft/releases/latest/download/naver-blog-draft-install.zip)**을 풀고 폴더를 Codex에 전달해 같은 문장으로 요청하면 됩니다. 설치 파일을 운영체제별로 직접 고를 필요가 없습니다. 공개 다운로드에는 GitHub 계정이 필요 없으며 Codex 설치·로그인과 이용 요금은 별개입니다.

**파일 설치만으로 컴퓨터 유즈·파일 첨부 권한이나 네이버 로그인이 추가되지는 않습니다.** 실행 도구 자체가 실패하면 재설치를 반복하지 않고 실패 단계를 구분합니다. 컴퓨터 유즈를 사용할 수 없으면 원고 작성까지만 가능합니다.

Codex에서 스킬 목록이 갱신된 뒤 다음처럼 요청합니다.

> $naver-blog-draft 이 사진들로 주말 일기를 같이 만들자. 글이 정리되면 네이버 블로그에 옮겨서 임시저장해줘.

사용 환경에는 네이버 웹 에디터를 조작하고 로컬 파일을 첨부할 수 있는 컴퓨터·브라우저 도구가 필요합니다. 이 저장소 자체가 브라우저를 실행하는 독립 프로그램은 아닙니다. 로그인이나 추가 인증은 사용자가 진행합니다. 원고 상담만 할 때에는 브라우저가 필요하지 않습니다.

개인 지침은 스킬 폴더 밖의 `$CODEX_HOME/naver-blog-draft/preferences.md`에 저장합니다. 기본 경로는 `~/.codex/naver-blog-draft/preferences.md`입니다. 이번 요청이 개인 지침보다 우선하며, 개인 지침은 배포 기본값보다 우선합니다. 업데이트할 때에는 스킬 폴더만 교체하고 개인 지침은 유지합니다.

## 검증 계획

검증 당일 [수동 검증 항목](VALIDATION.md)에 따라 테스트합니다. Mac 설치기는 임시 설치 경로에서 신규 설치·재실행·수정본 보호·개인 지침 보존을 검증했습니다. 설치 경로와 권한 예방 로직의 Windows 실기 재검증은 남아 있습니다. [설치 검증 기록](INSTALLATION-VALIDATION.md)을 참고하세요. 설치 검사와 스킬 형식 검사는 컴퓨터 유즈와 네이버 저장 성공을 의미하지 않습니다.

개인 사진, 원고, 계정 정보, 브라우저 세션, 실제 작업 기록은 배포물에 포함하지 않습니다.

## Claude에서 사용하기

지침은 Agent Skills 형식이므로 재사용할 수 있지만 현재 자동 설치기는 Codex용입니다. Claude Code에서 쓰려면 `.claude/skills` 설치 위치와 개인 지침 경로를 맞추고 실제 브라우저·파일 첨부 도구를 확인해야 합니다. 일반 채팅의 스킬 업로드만으로 로컬 브라우저 조작 권한이 생기지는 않습니다. Claude 환경의 실제 네이버 작성·임시저장은 검증 전입니다. [Claude Code 공식 스킬 문서](https://code.claude.com/docs/en/skills)를 참고하세요.
