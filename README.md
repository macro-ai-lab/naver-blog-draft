# naver-blog-draft

사진·영상과 대화로 네이버 블로그 글을 만들고, 컴퓨터 유즈로 스마트에디터 ONE에 옮겨 **임시저장까지** 진행하는 Codex 스킬 초안입니다.

**상태: v0.1.1 초안. 실제 네이버 계정에서의 업로드·임시저장·재열람은 아직 검증하지 않았습니다.** 자동 발행·예약 발행·반복 게시 기능은 포함하지 않습니다. `daily-vlog`와 독립적으로 사용할 수 있으며, 완성된 브이로그를 첨부 자료로 받을 수 있습니다.

## 설치와 사용

1. **[설치 ZIP 다운로드](https://github.com/macro-ai-lab/naver-blog-draft/releases/latest/download/naver-blog-draft-install.zip)** 후 압축을 해제합니다.
2. 압축 해제한 폴더를 Codex 채팅에 끌어 넣고 **“이 폴더의 네이버 블로그 스킬을 설치해줘”**라고 요청합니다.
3. 설치가 끝나면 Codex에서 새 채팅을 열어 아래처럼 요청합니다.

직접 설치하려면 Mac은 `install.command`, Windows는 `install-windows.cmd`를 실행합니다. 설치 폴더를 직접 찾아 복사하거나 Python을 준비할 필요가 없습니다. 다운로드 보안 경고나 실행 차단이 나오면 Codex에 해당 메시지를 알려주세요. 보안 설정을 끄지 않아도 됩니다.

설치기는 `$CODEX_HOME/skills/naver-blog-draft`에 스킬만 추가합니다. 기본 경로는 `~/.codex/skills/naver-blog-draft`입니다. 같은 내용이면 설치 완료로 안내하며, 다른 버전이나 수정본은 덮어쓰지 않습니다. 이 경우 Codex에 갱신을 요청하세요. 개인 지침과 다른 스킬은 바꾸지 않습니다.

Codex에서 스킬 목록이 갱신된 뒤 다음처럼 요청합니다.

> $naver-blog-draft 이 사진들로 주말 일기를 같이 만들자. 글이 정리되면 네이버 블로그에 옮겨서 임시저장해줘.

사용 환경에는 네이버 웹 에디터를 조작하고 로컬 파일을 첨부할 수 있는 컴퓨터·브라우저 도구가 필요합니다. 이 저장소 자체가 브라우저를 실행하는 독립 프로그램은 아닙니다. 로그인이나 추가 인증은 사용자가 진행합니다. 원고 상담만 할 때에는 브라우저가 필요하지 않습니다.

개인 지침은 스킬 폴더 밖의 `$CODEX_HOME/naver-blog-draft/preferences.md`에 저장합니다. 기본 경로는 `~/.codex/naver-blog-draft/preferences.md`입니다. 이번 요청이 개인 지침보다 우선하며, 개인 지침은 배포 기본값보다 우선합니다. 업데이트할 때에는 스킬 폴더만 교체하고 개인 지침은 유지합니다.

## 검증 계획

검증 당일 [수동 검증 항목](VALIDATION.md)에 따라 테스트합니다. Mac 설치기는 임시 설치 경로에서 신규 설치·재실행·수정본 보호·개인 지침 보존을 검증했습니다. Windows 설치기는 실제 Windows 환경 검증 전입니다. 설치 검사와 스킬 형식 검사는 컴퓨터 유즈와 네이버 저장 성공을 의미하지 않습니다.

개인 사진, 원고, 계정 정보, 브라우저 세션, 실제 작업 기록은 배포물에 포함하지 않습니다.
