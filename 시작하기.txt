가장 쉬운 방법: GitHub 주소로 설치 요청
Codex에 아래 주소와 문장을 함께 보내세요. ZIP을 직접 받을 필요가 없습니다.

https://github.com/macro-ai-lab/naver-blog-draft

이 GitHub 저장소의 README와 naver-blog-draft/SKILL.md를 읽고,
내 운영체제에 맞게 네이버 블로그 스킬을 설치해줘.
기존 스킬은 덮어쓰지 말고 버전과 수정 여부를 확인하고 개인 지침은 보존해줘.
컴퓨터 유즈와 파일 첨부 도구의 사용 가능 여부도 확인해줘.
네이버 글 작성이나 업로드는 아직 하지 마.

ZIP으로 설치하고 싶다면
1. 다운로드한 ZIP을 완전히 압축 해제합니다.
2. 압축 해제한 폴더를 Codex 채팅에 끌어 넣고 말합니다.
   “이 폴더의 네이버 블로그 스킬을 설치해줘.”
3. 설치 후 새 Codex 채팅을 열고 사진과 이야기를 전달합니다.
   “네이버 블로그 글을 같이 만들고, 정리되면 임시저장까지 해줘.”

직접 설치: Mac은 install.command, Windows는 install-windows.cmd를 실행합니다.
Windows 설치기는 실제 Windows 검증 전입니다.
실행 차단이나 오류가 뜨면 해당 메시지를 Codex에 알려주세요.
관리자 비밀번호나 Python 설치는 필요하지 않습니다.

파일 접근과 컴퓨터·브라우저 조작을 지원하는 Codex 환경이 필요합니다.
스킬 설치만으로 컴퓨터 유즈 권한이나 네이버 로그인이 설정되지는 않습니다.
일반 웹 채팅이나 휴대폰에서 ZIP만 업로드하는 방식은 지원하지 않습니다.

같은 스킬은 재실행해도 되며, 수정본이나 다른 버전은 자동 덮어쓰지 않습니다.
개인 지침은 별도 경로에 유지됩니다. 갱신은 Codex에 요청하세요.

이 버전은 원고 작성과 임시저장용 초안입니다. 실제 네이버 동작 검증은 남아 있습니다.
발행·예약 발행은 하지 않습니다. 로그인·추가 인증은 직접 진행합니다.
